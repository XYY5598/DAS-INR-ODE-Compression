## 工业部署解读

- **流式监测**（权重预部署、每秒上传潜向量）：压缩比 **146× 满足专利**
- **PSNR 40 dB**：CPU 120 epoch 下未达成；需 GPU + 200 epoch + 更长 latent 精调
- **首包成本**：约 1.46 MB 模型权重，适合边缘节点一次性加载

## 达到 40 dB 的路径估算

参考 DAS-reconstruction SIREN：20 层、lr=1e-5、8 epoch@GPU 可达可用重建。

本实现 120 epoch@CPU → 26 dB；外推 200–300 epoch 或 GPU 加速，**有望达到 35–42 dB**（需实测）。

```bash
# 完整训练（建议 GPU）
python scripts/run_improved_benchmark.py --only B_time_INR --inr-epochs 200 --ode-epochs 0
```
